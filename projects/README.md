# Projects

`clean-install` intentionally ships without any project implementations.

This directory is reserved for future project materialization only.

## Rule

Before adding any project under `projects/`, create and approve explicit task tracking first:

1. create the project task or epic in AgentPlane;
2. define scope, authority boundaries, verification, and runtime ownership;
3. only then materialize the project files.

## Current Branch Contract

- keep this directory otherwise empty;
- do not commit private or example application code here;
- do not treat past private projects as part of the canonical DEUS install surface.
